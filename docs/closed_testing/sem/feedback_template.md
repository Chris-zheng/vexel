## C. 内测结束时的问卷

1. 首次上手（不看手册）用了多少分钟？在哪里卡住？
2. 标定：有没有读错的像素尺寸？标定条的提示是否清楚？
3. 线宽：与 CD-SEM 相比，在相同的边缘定义下差多少？可以接受吗？
4. 自动规划：选对方法的比例大约多少？理由是否看得懂、有没有用？
5. 你最希望增加或改进的三件事是什么？
6. 你愿意在日常工作中用它做哪些事？还缺什么才能用？

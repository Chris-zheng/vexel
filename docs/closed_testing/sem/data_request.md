# SEM 测试数据需求

最有价值的是：线条与间隔图案的原始图像，附上 CD-SEM 自己给出的线宽及其算法设置，以及同一位置的重复拍摄。有了这些，才能把 Vexel 的结果与贵司现有设备对比，并测出重复性。

## 文件要求

请提供仪器直接保存的原始文件，不做任何改动。软件从文件内的仪器元数据和图像下方的信息栏读取像素尺寸，改动过的文件无法验证这一步。

- **原始文件**：仪器保存的 TIFF，原样复制（不重新保存、不转格式、不压缩）。
- **旁车文件**：Hitachi、JEOL 等会在图像旁另存 `.txt` 或 `.hdr` 文件，记录像素尺寸等信息，请与图像一起提供，文件名保持一致。
- **保留信息栏**：不要裁掉图像下方的信息栏（比例尺、放大倍数、加速电压等）。
- **不要**截图、导出为 JPEG、缩放或在图上加标注。如果贵司日常确实使用导出或缩放后的图，请另外提供几张，并注明是怎样导出的。
- **每个文件夹附一份清单**（见“文件夹与清单”）：仪器型号、加速电压、放大倍数、探测器、样品台倾角、样品，以及参考值和它的测量方法。

## 需要的图像

优先级 1 的三项足以开始验证，其余可以随后补充。数量是建议的最低值，多多益善。

| 优先级 | 用途 | 需要的图像 | 数量 | 参考值 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 像素尺寸与标定 | 贵司在用的每一种 SEM / CD-SEM 型号（Hitachi CG 系列优先）；低、中、高三档放大倍数；有信息栏和没有信息栏的保存方式各几张 | 每种型号、每档倍数 5–10 张 | 每台仪器一张有证书的周期标准样品（标定光栅）图像及其证书值 |
| 1 | 线宽与边缘粗糙度 | 俯视的线条与间隔图案，贵司实际的周期；光刻胶与刻蚀后各有。如有焦距–曝光矩阵（FEM）晶圆最好：线宽应随剂量单调变化，可在没有真值时检验 | 10 个以上位置 | **CD-SEM 对每张图给出的线宽，以及它的算法设置**（阈值百分比、平滑、测量框、平均的线数）；如有 LER/LWR 也请提供 |
| 1 | 重复性 | 同一位置不移动连续拍 10 次以上；另在移开后重新导航（或重新上片）回到同一位置拍 5 次以上 | 3–5 个位置 | CD-SEM 对同一组图的测量值 |
| 2 | 接触孔与通孔 | 孔阵列，包括有缺失孔或相连孔的情况 | 10 张以上 | CD-SEM 的孔径；贵司对缺陷孔的判定 |
| 2 | 截面 | FIB 或裂片截面；多层膜；沟槽 | 10 张以上 | 拍摄与样品台倾角；椭偏或 TEM 测得的膜厚；如有，TEM 或 AFM 测得的侧壁角 |
| 2 | 颗粒与缺陷 | 缺陷复查图像；另一份已知粒径的标准微球样品（例如 PSL） | 图像 20 张以上；标准样品 1 份 | 缺陷检测系统给出的类别与尺寸；微球的证书粒径 |
| 3 | 图像处理 | 荷电（条纹、局部过亮）、漂移、扫描行错位、饱和区；同一区域的多帧（每帧单独保存） | 每种问题 5–10 张 | 如可能，同一区域的一张干净图像（低电压或镀膜后） |
| 3 | 自动识别图像类型 | 贵司希望软件自动识别的每一类图像，另加“其他”一类；覆盖不同仪器和倍数 | 每类 30–50 张 | 类别：按文件夹区分即可 |
| 4 | 倾转三维 | 同一区域的倾转图对或图组（例如 0°、±5°、±10°） | 3–5 个区域 | 台阶高度标准样品或 AFM 剖面 |
| 全部 | 异常情况 | 空白、失焦、快速扫描的高噪声图、严重荷电、图案旋转 | 10–20 张 | 无：软件应当拒绝或警告，而不是猜测 |

线宽对比需要 CD-SEM 的算法设置：边缘定义不同，测得的线宽就不同。没有设置，就无法判断两者的差异是误差还是定义不同。

## 文件夹与清单

按“用途 / 样品或位置 / 文件”三层存放。同一位置的重复拍摄放在同一个文件夹：软件按文件夹计算重复性（平均、标准差、3σ）。

```text
SEM数据/
  1_标定/        Hitachi_CG6300_标准光栅/   文件 + 清单.csv
  2_线宽/        层M1_光刻胶_位置03/         文件 + 清单.csv
  3_重复性/      层M1_位置03_不移动/          文件 + 清单.csv
                 层M1_位置03_重新导航/        文件 + 清单.csv
  4_接触孔/ 5_截面/ 6_颗粒缺陷/ 7_图像处理/ 8_分类/ 9_倾转/ 10_异常/
```

清单每张图一行，空着的列可以不填。参考值请写明单位和测量方法：

```csv
文件,仪器型号,加速电压(kV),放大倍数,探测器,样品台倾角(°),样品/层,参考值,单位,参考值来源与设置,备注
site03_001.tif,Hitachi CG6300,0.8,150000,SE,0,M1 光刻胶,32.4,nm,"CD-SEM, 阈值 50%, 平滑 3, 平均 16 条线",
site03_002.tif,Hitachi CG6300,0.8,150000,SE,0,M1 光刻胶,32.6,nm,"CD-SEM, 同上",不移动重拍
```

## 保密与使用约定

数据只在开发方本地计算机上使用，不进入代码仓库，不上传到任何云服务或大模型。以下事项请在提供数据前确认：

- [ ] 信息栏或文件名中的产品名、批号、层名是否保密？如保密，可以用代号重命名文件，但请不要改动图像本身。
- [ ] 是否允许把少量经过脱敏的小块图像保留为自动回归测试，用于每次软件更新后的检查？
- [ ] 测试结束后数据如何处理：删除，还是保留到约定日期？
- [ ] 结果与对比报告可以给哪些人看？
- [ ] 由谁负责解答数据和参考值的问题（例如 CD-SEM 的算法设置）？

# Vexel 0.7.0b2 SEM 模块内测说明（给测试者）

感谢参加 Vexel SEM 模块的内测。Vexel 的 SEM 模块读取 SEM / CD-SEM 图像，自动标定像素尺寸，测量线宽与线边缘粗糙度（LER/LWR）、接触孔、截面层厚与侧壁角、颗粒与缺陷，并给出重复性。所有计算都在你的电脑上完成。

这是**预览版**：功能已经齐全，标定与颗粒测量已在真实图片上验收过两轮，但**半导体计量还没有在真实的 CD-SEM 图像上验证过**。这正是这次内测最需要的：用贵司的真实图像，把 Vexel 的结果和贵司现有的 CD-SEM 结果放在一起比。

> **0.7.0b2 的新功能**（已装 0.7.0b1 的，按第 1 节重新安装即可，记录与设置会保留）：**点选纠错**——结果不对时在图上点几个例子，Vexel 换设置重测并给出候选；**方案**——把满意的测量存起来，一键用在别的图上，或打开图片时自动套用；**批量测量**——用方案测一批图，需要看的排在前面。另外，空白或纯噪声的区域不再给出数值。见第 3.4 节。

## 内测安排

| 项 | 内容 |
| :--- | :--- |
| 时间 | 约 2–3 周，期间约 3–5 小时 |
| 你需要 | 一台 Windows 10/11、macOS 或 Linux 电脑；贵司 SEM / CD-SEM 保存的原始图像，以及 CD-SEM 对这些图像给出的测量值和算法设置 |
| 你会做 | 安装 → 首次上手（计时）→ 标定核对 → 线宽与粗糙度对比 → 重复性 → 反馈 |
| 联系 | 组织者会告诉你用哪个微信群 / 邮箱提交反馈 |

## 1. 安装（约 10–20 分钟）

你会收到三个文件，放在同一个文件夹里：

| 文件 | 作用 |
| :--- | :--- |
| `vexel-0.7.0b2-py3-none-any.whl` | Vexel 本身 |
| `vexel-0.7.0b2-constraints.txt` | 我们测试过的全部依赖的确切版本 |
| `SHA256SUMS.txt` | 前两个文件的校验值 |

先核对文件完整：macOS / Linux 运行 `shasum -a 256 -c SHA256SUMS.txt`；Windows 运行 `Get-FileHash .\vexel-0.7.0b2-py3-none-any.whl`，与 `SHA256SUMS.txt` 对比。

安装 uv（Python 工具管理器）。海外网络和中国大陆网络的做法见液滴内测说明的 [第 1 节](../README.md#1-安装约-1020-分钟)：大陆网络请按其中 1B 设置好 USTC 与清华镜像。然后在放安装文件的文件夹里运行（**注意文件名后的 `[sem]` 和引号**，它装上读取信息栏文字所需的组件）：

```bash
uv tool install "./vexel-0.7.0b2-py3-none-any.whl[sem]" -c ./vexel-0.7.0b2-constraints.txt
```

Windows 第一次安装后再运行一次 `uv tool update-shell`，然后重新打开 PowerShell。

**启动 SEM 窗口**（SEM 模块是预览版，要加 `--preview`）：

```bash
vexel gui --module sem --preview
```

想做成桌面快捷方式：快捷方式的目标填 `vexel-gui` 的完整路径（`where vexel-gui` 查看），后面加上 ` --module sem --preview`。

Intel 芯片的 Mac 不支持读取信息栏文字，只能用仪器元数据或手动标定。

## 2. 首次上手（约 15 分钟，请计时）

> 这一步也是可用性测试：**请先不看手册**，记下用了多少分钟、在哪里卡住。

1. 点工具栏 **打开…**，打开一张线条与间隔（line/space）的原始图像。
2. 看右上角的**标定条**：像素尺寸和它的来源。橙色表示从信息栏读出、等你确认，核对无误后点 **确认**。
3. Vexel 会自动识别图像并试测，结果画在图上，“自动测量”页顶部的卡片给出线宽等关键数值。点 **采用** 加入记录，或 **调整** 改设置。
4. 试着得到：这张图的平均线宽、LER 3σ，并导出 Excel。

## 3. 主要任务

请参照 [数据需求](data_request.md) 准备图像（原始文件，保留信息栏；Hitachi、JEOL 的 `.txt` 旁车文件一起复制）。

### 3.1 标定核对（约 20 分钟）

每种仪器型号、每档放大倍数各打开 3–5 张图，在反馈表中记下：Vexel 的像素尺寸、来源（元数据 / 信息栏 / 手动）、与贵司已知值是否一致。有证书的标定光栅图像时，用 **测量** 页的 **线剖面** 量它的周期，与证书值比较。

### 3.2 线宽与粗糙度对比（主要任务，约 1–2 小时）

对 10 个以上位置的线条与间隔图像：

1. 打开图像，采用自动规划，或在“自动测量”页选 **线条与间隔（CD、LER/LWR）**，框选一组完整的线条（两侧边缘都在框内，沿线方向尽量长）后点 **运行**。
2. **把边缘定义设成和贵司 CD-SEM 一样**（这一步决定能否对比）：选中这项自动测量，展开 **高级设置**：
   - CD-SEM 用阈值法（例如 50%）：“边缘定义”选 **阈值**，“阈值”填同一比例（0.5）；
   - 用最大斜率法：选 **最大梯度**；
   - CD-SEM 的平滑与平均的线数：分别填 **平滑** 与 **行平均**。
   改动后结果自动重算。
3. 在反馈表中记下：Vexel 的线宽（平均、各线）、LER/LWR 3σ，CD-SEM 的值及其设置，两者的差。
4. 结果明显不对时：导出诊断包（见第 4 节），并告诉我们是哪张图。

### 3.3 重复性（约 30 分钟）

把同一位置连续拍的图放在一个文件夹，在终端里：

```bash
vexel sem analyze 文件夹路径/*.tif -r lines -o 重复性.xlsx
```

Excel 的“重复性”页给出每个结果在这组图上的平均、标准差与 3σ。和 CD-SEM 对同一组图的重复性比较。

### 3.4 点选纠错、方案与批量（约 30 分钟）

1. **点选纠错**（颗粒与缺陷、孔隙、接触孔）：结果里漏了对象或多了不该有的，选中这项测量，点 **点选纠错**，在图上**左键**点几个应该测到的、**右键**点几个不该测到的，点 **按例子调整**，从并排的候选里选一个。请记下：点了几个例子、等了几秒、候选里有没有对的。
2. **方案**：线宽测量设置好之后（边缘定义与 CD-SEM 一致），选中它点 **存为方案…**，起个名字（例如“M1 线宽”）。打开同类的下一张图，选这个方案点 **应用方案**；或勾选“打开图片时自动套用这个方案”，看下一张图打开后是否直接测好。
3. **批量测量**：选中方案，点 **批量测量…**，选一批同类的图（例如第 3.3 节的重复拍摄）。看排在前面的“需要看”是不是真的有问题，正常的那些是否确实不用看。可以导出 Excel 和 CD-SEM 的结果对比。

### 3.5 可选：接触孔、截面、颗粒与缺陷

有时间的话，按数据需求中优先级 2 的图像各试几张：“自动测量”页的 **接触孔与通孔**、**截面层厚**、**截面轮廓（侧壁角）**、**颗粒与缺陷**。截面图在倾斜样品台下拍摄时，在 **测量** 页勾选倾斜校正。

完整说明见 [用户手册](../../user_manual.md) 第 11 章。

## 4. 反馈

每完成一组图像，或遇到一个问题，填一份 [反馈表](feedback_template.md)。出错、崩溃或结果明显不对时，请附上**诊断包**：

- SEM 窗口菜单 **帮助 → 诊断包…**（当前这张图）；
- 或命令行：`vexel bugreport --sem 图像.tif -o 诊断包.zip --note "发生了什么"`（`--sem` 可以写多次）。

诊断包包含软件版本、操作系统、这张图的标定与测量记录（坐标与设置）；**不含图像，也不含信息栏上识别出的文字**（产品名、批号常写在那里）。发送前可以解压查看。

**图像本身**请按 [数据需求](data_request.md) 中的保密约定另行提供；没有约定前不要发送。

## 5. 隐私与数据

- 所有分析都在你的电脑上完成，不联网，不上传任何东西。
- **自动规划**默认只用离线规则。如在液滴窗口的 帮助 → 规划模型设置 中选了云端大模型，Vexel 只发送数字特征和你写的目标，**不发送图像**。在公司内建议保持离线：设置环境变量 `VEXEL_OFFLINE=1`，或由 IT 部门放置组织策略文件（见用户手册第 12 章）。
- Vexel 不收集使用统计。我们只能看到你主动发来的反馈、诊断包和图像。
- 标定确认与测量记录保存在 `~/.vexel/sem/`（Windows 为 `C:\Users\用户名\.vexel\sem\`），按文件内容识别，不含图像。

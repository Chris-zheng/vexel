# 已知问题与限制：液滴模块与平台（0.7.0b2，2026-11-28 核对）

已知的问题不必再报；如果它影响了你的实验，请告诉我们影响有多大，这决定修复的先后。SEM 模块的已知问题见 [sem/known_issues.md](sem/known_issues.md)。

## 安装与平台

- 只在 macOS（Apple Silicon）上完整测试过；Windows、Linux、Intel Mac 预期可用但**未测试**。这次内测请特别留意安装与界面显示问题。
- 没有安装包，需要先装 uv；第一次启动要联网下载依赖。
- 视频按 RGB 三通道解码，灰度视频会多占内存；很长的高分辨率视频建议先截短试用。

## 数据

- 只分析 2D 时序（一个 z 平面）；各通道分存为不同文件时需先合并。
- 视频文件里的帧率常与实际不符（慢放、转码）；请手动填写帧间隔。没有像素尺寸时结果以像素为单位。
- 液滴不流动的静态阵列/腔室芯片、长条塞子、严重变形的液滴、双重乳液不支持。

## 分析

- 内置配方假定液滴是圆的；液滴大小差别很大时要手动给直径范围（高级设置）。
- 细胞计数：细胞前后完全重叠时会少数；紧贴液滴暗环的细胞会漏数。WSCNet 真实数据上 96% 的液滴细胞数正确。压缩过的视频（JPEG、MP4）里轮廓阴影和小杂质可能被数进去，需要在高级设置里调高检测阈值（用户手册第 7 节）。
- 荧光：只支持一个荧光通道；只有一群液滴时无法区分“全阴”与“全阳”，一律按阴性处理并提示；**尚未在真实荧光数据上验证**。
- 体积按 2D 直径和流道高度的理想几何换算，未校准。
- 人工修正后整段重算，长视频可能要几分钟；轮廓修改只作用于单帧。
- 画笔训练只区分“液滴/背景”两类。

## 自动规划

- 只在四个内置液滴配方中选择和调整设置，不会设计新流程。
- 默认的离线规则引擎在合成数据上 12/12 通过，在两段真实录像上给出“check”（能跑但有质控提示）。
- 云端大模型（Claude、DeepSeek、通义千问、Gemini）的效果尚未系统测量；需要你自己的 API 密钥。服务商的模型名会变，如提示模型不存在，请在 帮助 → 规划模型设置 里改成服务商当前的模型名。
- 0.8 起云端模型改为经 Vexel 网关使用（不再需要、也不再接受自己的密钥），在此之前测试版默认只用离线规则。

## 批量分析

- 分组统计只做单因素比较；多因素、配对设计、剂量–反应拟合尚未提供。
- 统计以“重复”为单位：没有填写 replicate 列时每个文件算一个重复；同一芯片的多段录像请填同一个 replicate，否则检验会高估证据。
- `reproduce.py` 要逐位一致，需要同一版本的 Vexel。

## 尚未提供

- 液滴模块与模块选择窗口的英文界面（SEM 窗口已有英文）；液滴结果的 Excel 格式导出（CSV 可用 Excel 打开；SEM 已可导出 Excel）。
- 点击式分割（SAM）、深度学习模型：液滴与细胞的识别模型在 0.8 计划中（训练好的模型以 ONNX 导入本地使用）。
- 三维数据与大型图像（多 GB、拼接大图）：移到 0.8 之后的阶段。
- 相机直连（目前通过监视采集文件夹实现边采边分析）。

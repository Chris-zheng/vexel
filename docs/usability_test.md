# 新用户可用性测试（第四阶段验收）

路线图第四阶段的验收标准：**新用户不看文档，15 分钟内完成一次分析。** 这只能由真人测试。本文是测试方案和记录表；每次测试约 30 分钟（含事后访谈）。

## 参加者

- 5 位没用过 Vexel 的人，最好是会做微流控液滴实验、但不熟悉图像分析软件的研究生或技术员。
- 每人单独测试。主持人只观察、计时、记录，不提示操作；参加者卡住超过 3 分钟可以请求提示，提示一次记一次。

## 准备

- 一台装好 Vexel 的电脑（`uv run vexel gui`，或安装包）。首次启动，引导栏应显示（清除设置或在“帮助 → 显示引导”打开）。
- 数据：A. 示例数据（界面里“试用示例数据”）；B. 一段参加者自己实验室的液滴视频（尽量带已知的像素尺寸与帧率）。
- 秒表、本记录表、录屏（征得同意后）。

## 任务（念给参加者听，不给书面步骤）

1. “这是一个分析液滴视频的软件。请用它分析这段示例视频，告诉我液滴的平均直径和每个液滴平均有多少个细胞。”
2. “现在换成你们自己的这段视频，同样得到平均直径和生成频率，并把报告保存下来发给同事。”
3. （可选）“报告说有几个液滴需要人工确认。请看一看，有错的话改正它。”

## 判定

- **通过**：至少 4 / 5 人在不看文档、不超过 1 次提示的情况下，15 分钟内完成任务 2，结果正确。
- 任务 1 用来熟悉界面，不计入判定，但用时超过 10 分钟说明首次上手有问题。
- 每个“卡住的地方”都要在下一版界面里处理，处理后再测。

## 事后访谈（5 分钟）

1. 哪一步最不确定该做什么？
2. 引导栏有没有帮助？哪句话看不懂？
3. 结果你信得过吗？为什么？
4. 什么情况下你会用“画笔训练”或“复核与纠错”？

## 已知风险（测试时特别留意）

- 视频文件里的帧率常是回放帧率，不是相机帧率：参加者是否注意到标定提示并改正。
- 不知道像素尺寸时是否能继续（结果以像素为单位）。
- 预览后能否判断“红线套准了没有”。
- 画笔训练：是否理解两支画笔的含义，是否会在出错处补笔。

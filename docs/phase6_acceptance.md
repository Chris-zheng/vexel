# 第六阶段（批处理与统计）验收记录

日期：2026-11-14。复现：`uv run python tests/benchmarks/batch_acceptance.py`（约 7 分钟）。

## 验收标准（路线图第十节）

> 100 个文件无人值守完成，导出脚本可独立复现。

## 方法

- **数据**：合成录像，有精确真值。4 个条件 × 5 块芯片（重复）× 每块 5 段录像 = 100 段。条件 `ctrl` 与 `ctrl_repeat` 参数相同（不应报出差异），`bigger` 液滴直径大 8 µm，`more_cells` 每滴细胞数 λ 从 0.5 提到 1.2。同一块芯片上的录像共享一个小的直径偏移，模拟“芯片之间有差异”：这正是统计必须以芯片为单位的原因。
- 设计表另加 1 个损坏的视频和 1 个不存在的文件，检验单个文件出错不会中断批量。
- 用 `droplet_encapsulation` 配方运行。处理 30 个文件后要求停止，再运行同一命令续跑。
- 续跑完成后，在新进程中运行导出的 `reproduce.py`：重新分析全部文件、重算统计，逐个核对结果摘要（全部表格与汇总的 SHA-256）。
- 检查统计是否找出设定的差异，且没有报出不存在的差异。

## 结论

1. **无人值守**：100 个文件全部完成，损坏和缺失的文件各记录一条原因，批量没有中断；中途停止后续跑，已完成的 30 个直接沿用，不重算。
2. **独立复现**：导出脚本在新进程中重跑全部 100 个文件，结果摘要逐个一致，统计表完全相同。
3. **结果正确**：100 个文件的液滴数、粒径、细胞数都在 `vexel validate` 的容差内与真值一致。
4. **统计**：以芯片为单位（20 个重复）找出了设定的直径差异和细胞数差异（Holm 校正后 p < 0.001），在相同条件之间、以及没有设定细胞数差异的组之间都没有报出差异。

## 局限

- 只用了合成数据。真实多条件实验（不同流速比、不同细胞浓度）的批量分析需要内测数据。
- 只在一台机器（Apple Silicon，macOS）上测过；文件依次处理，每个文件内部用多线程。
- 统计只做单因素比较；多因素、配对设计、剂量–反应尚未提供。

# 微流控液滴（S1）开发进度评估

日期：2026-11-14。对照：`vexel_roadmap_0.0.3.md` 第七节 S1 功能、第十节阶段与验收标准。版本：0.5.0b1（第五阶段完成后的内测版）。

## 一句话结论

**S1 的分析功能已经齐全**：单个录像从读入、分割、去重计数、粒径/体积、包裹与泊松、荧光阴阳判读，到在线监控、人工复核、画笔训练、自动规划，都能在命令行和桌面界面完成，在合成数据上与真值一致，在两段真实录像上计数完全正确。**还不能交给客户 beta**，差的主要不是功能，而是：真实数据验证太少（2 段录像、无客户数据）、批处理与实验级统计（第六阶段）、安装包（第七阶段）、三个需要真人或凭据的验收（15 分钟可用性、联网规划通过率、客户审阅报告）。适合现在做**小范围内测（closed testing）**：找 3–5 位懂液滴实验的人，用源码安装，用他们自己的录像，目的是收集真实数据和失败案例。

## 一、S1 功能逐项（路线图第七节）

| 功能 | 状态 | 证据 | 欠缺 |
| :--- | :--- | :--- | :--- |
| 粒径均值、标准差、CV | ✅ 完成 | 合成回归 9 例全部与真值一致；真实 .mov 测得 52.3 µm（比例尺目测约 50 µm） | 没有独立测量的真实粒径参照（如显微镜标定液滴、单分散微球） |
| 压扁液滴按流道高度换算体积 | ✅ 完成（理想几何） | 合成 `basic_flattened` 一致 | 未用三维形状校准；真实数据未验证 |
| 跨帧去重（追踪 + 虚拟计数线） | ✅ 完成 | 真实 .mov 9/9、WSCNet 134/134，越线时刻差 < 1 帧 | 只两段真实录像；没有测过液滴碰撞、合并、断裂 |
| 包裹计数、空/单/多比例、泊松拟合 | ✅ 完成 | 合成一致；WSCNet 132 个确定液滴中 122 个细胞数正确（92%），λ 1.49 vs 人工 1.57 | 前后重叠的细胞少数；贴暗环的细胞漏数；真值只一人标注 |
| 尺寸–荧光散点、阳性率 | ✅ 完成（单色） | 合成 3 例（清晰、全阴、重叠分布）一致 | **无真实荧光数据验证**；不支持多色；全阳性无法与全阴性区分 |
| 生成频率、间距、速度 | ✅ 完成 | 合成一致；真实 .mov 越线时刻一致 | 真实数据帧率常不可靠（.mov 疑为慢放），需用户给帧率 |
| 流式滚动值与报警 | ✅ 完成 | 第三阶段验收：跟得上时在线与全量 100% 一致；超负荷抽样有处理能力报警 | 只测过短的真实录像；未接相机（按计划推迟） |
| 分布漂移检测 | ✅ 部分 | 流式下粒径、频率相对首个窗口漂移报警 | 只看粒径与频率，不看指纹漂移；不触发重规划 |

**不在路线图 S1 中、但客户可能会要的**（内测时注意收集需求）：静态阵列/腔室式数字 PCR（液滴不流动）、双重乳液、长条塞子、多色荧光、液滴分选的触发信号、与生成条件（流速比、黏度）的关联分析。

## 四、验证证据汇总

- **自动测试**：单元与集成测试 170 余项、合成回归基准 9 例，每次修改都跑。
- **合成数据**：生成器给出精确真值（粒径分布、泊松参数、轨迹、荧光拷贝数），覆盖噪声、小而快、大而慢、多分散、密集细胞、低对比细胞、荧光重叠、全阴性、竖直流动。
- **真实数据**：
  - `DropletMicrofluidics.mov`：101 帧流动聚焦，计数与越线时刻全对。
  - WSCNet2 示例：300 帧、134 个液滴，计数全对，细胞数 92% 正确。
- **已下载但尚未接入的公开数据**：`droplet_detection-master`（Gardner 等，0/1/2/3+ 细胞分类，**正好可验证包裹计数**）、`DropletTracking-main`（DropTrack，液滴框，可验证检测与追踪）、`Droplet-Bead` YOLO 集（液滴–珠子）、`single and double emulsion generation`、`uDrop-Generation`，以及几份生成条件与粒径的表格。各自许可证尚未核实（路线图待确认事项第 4 条）。

## 五、主要缺口，按对内测的影响排序

**内测前应补（本次已补的打 ✓）**

1. ✓ 测试者文档：快速上手、内测说明、反馈模板、已知问题（见 `docs/closed_testing/`）。
2. ✓ 一键诊断包 `vexel bugreport`：测试者出问题时导出不含原始图像的诊断信息。
3. ✓ 模型选择与隐私说明：测试者在中国大陆时可选 DeepSeek / 通义千问，或完全离线。
4. 至少在一台 Windows 或 Linux 机器上跑通安装和测试（目前只在 macOS 运行过）。

**内测期间并行做**

5. 接入 Gardner 数据集，验证包裹计数（这是目前最弱的真实验证环节）。
6. 收集测试者的录像（征得同意）和人工修正，作为第一批客户数据；请第二人复核细胞数真值。
7. 真人做 15 分钟可用性测试（可与内测合并：第一次使用时录屏计时）。
8. 有凭据时跑联网规划验收：`uv run python tests/benchmarks/agent_acceptance.py --model deepseek`（或 claude / qwen / gemini）。

**正式 beta 前**

9. 第六阶段：批处理、实验设计表、分组统计、脚本导出、英文 Methods。
10. 第七阶段：三平台安装包、签名公证。
11. 真实荧光（ddPCR）数据验证；真实粒径参照。
12. 与合作课题组确定“约定阈值”（计数、粒径、细胞数的允许偏差），写成指标确认单。

## 六、风险

| 风险 | 现状 | 建议 |
| :--- | :--- | :--- |
| 真实数据与合成数据差异大 | 只 2 段真实录像；第五阶段两段真实录像规划状态都是 check | 内测的首要目的就是拿真实数据；每个失败案例进回归集 |
| 测试者的录像不是“流过直通道的圆液滴” | 静态阵列、塞子、双乳液都不支持 | 内测说明里写清适用范围；收到不适用的数据记为需求 |
| 帧率/像素尺寸元数据不可信 | 视频常没有或有错 | 界面和文档都提醒填写；报告标注“未标定” |
| 安装失败劝退测试者 | 源码安装需 uv、需联网下载依赖 | 内测说明给出逐步命令；必要时远程协助 |
| 数据外传顾虑 | 默认离线规则；云端模型只发数字 | 内测说明的隐私一节写清楚 |

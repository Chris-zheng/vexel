# Vexel 0.8 功能清单与定级（阶段 0）

状态：**已确认**（2026-11-28），文末四项已按建议实施。这是 [0.8 计划](plan_0.8.md) 验证门 0 的第一项。

## 定级的含义

| 定级 | 含义 |
| :-- | :-- |
| **保留** | 进入 0.8 正式界面，有验收证据，出了问题当缺陷修。 |
| **保留·待真实验证** | 进入界面，结果旁注明“只在合成图像上验收过”，直到有真实图片的对比。 |
| **预览** | 默认隐藏，设置 `VEXEL_PREVIEW=1` 才出现；不对测试者承诺。 |
| **开发者** | 只在命令行或文档中，不出现在桌面界面。 |
| **下一阶段** | 0.8 不做新开发，界面里隐藏。 |
| **替换** | 0.8 中由新方案取代。 |

证据栏写出验收依据：测试文件、基准脚本（`tests/benchmarks/`），或真实数据的结果。

## 已确认并实施的几项（2026-11-28）

1. **荧光阴阳判读**改为预览，直到有真实荧光数据。
2. **嵌套区域**与**导线与焊盘**两个新测量先作为预览，不给测试者。
3. **云端模型档位**（用户自填密钥）在网关上线前改为预览，测试版默认只有离线规则。
4. 半导体计量（线宽、孔、层厚、侧壁角、尖端）、孔隙、纤维保留在界面中，但结果旁注明“只在合成图像上验收过”。

实施方式：设置环境变量 `VEXEL_PREVIEW=1` 时，预览功能全部出现。荧光判读在没有预览时隐藏，但自动规划或已存设置打开它时会显示，并标明“预览”；含有嵌套区域或导线与焊盘测量的旧记录仍可打开和重算；`vexel plan --model …` 在命令行上仍可显式选用云端模型（开发用）。

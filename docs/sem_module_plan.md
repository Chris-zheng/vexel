# SEM 模块前期开发计划书（草案，待确认）

日期：2026-11-18。状态：**已确认（2026-11-18），按第七节的调整执行**。

**进度**：M0（平台模块化、企业离线策略、离线安装包）已完成（2026-11-19），见 [平台模块](modules.md)。下一步 M1（读取与自动标定）。依据：你提出的功能设想、对现有代码的检查、对 SEM 元数据格式、标定、图像处理、分割、分类、倾转三维重建、公开数据集与同类软件的检索（来源见文末）。

## 一、目标与原则

**目标**：在 Vexel 平台上新增一个 SEM 模块，与微流控模块并列、独立运行。覆盖：

- 手动二维测量：长度、面积、角度、周长、计数；
- 自动标定与信息栏裁剪；
- SEM 常见图像处理（荷电伪影、亮度对比度等）；
- 常见分割：颗粒、纤维、尖端；
- 图像与目标的自动分类；
- 倾转多角度成像的三维重建。

**原则**（沿用平台已有做法）：

1. **两个模块共用一个平台。** 共用的有数据底座、算子注册表、配方引擎、溯源、质控、批处理与分组统计、报告框架、插件接口、智能体、诊断包。模块各自提供算子、配方、界面工作区、报告内容和验证数据。一个模块出问题不影响另一个。
2. **标定必须可追溯。** 每张图的像素尺寸都记录来源（仪器元数据、信息栏识别、手动）和可信度。识别出来的标定要人确认后才算数。
3. **处理不改变测量的依据。** 图像处理只用于显示和分割，测量始终在已标定的原始几何上进行。每一步处理都写入溯源记录；只为美观的处理（如锐化）单独标明。
4. **能用经典方法就不用深度模型。** 深度模型只作为插件接入，记录许可证和训练数据（第六阶段的插件接口已经就绪）。
5. **每项自动功能都要有可量化的验收**：合成数据给出精确真值，真实数据给出人工参照。

## 二、调研结论与推荐做法

### 2.1 读取与自动标定

**最可靠的标定来自仪器写在文件里的元数据，其次才是识别图片下方的信息栏。** 推荐三级来源，依次尝试：

| 级别 | 来源 | 做法 | 可信度 |
| :--- | :--- | :--- | :--- |
| 1 | 仪器元数据 | Thermo Fisher（FEI）：TIFF 私有标签 34680/34682 中的 INI 文本，`PixelWidth` 单位为米；Zeiss：标签 34118（SmartSEM 参数块，“Image Pixel Size”）；TESCAN：同名 `.hdr` 文本，`PixelSizeX/Y` 单位为米；Hitachi：同名 `.txt` 中的 `PixelSize`；JEOL：同名 `.txt`，字段名待用真实文件核对。`tifffile` 已能解析 FEI 与 Zeiss 的标签 | 高，自动采用 |
| 2 | 信息栏识别 | ① 找到信息栏（见下）；② 在信息栏和图像下部找比例尺线段，测其像素长度；③ 识别比例尺旁的数字和单位，以及放大倍数、视场宽度（HFW）、工作距离；④ 交叉核对：比例尺换算出的像素尺寸与视场宽度 ÷ 图像宽度应一致 | 中，**需人确认**；两种估计一致时可信度提高 |
| 3 | 手动 | 在比例尺两端各点一下并输入长度；或直接输入像素尺寸 | 由人负责 |

**文字识别（OCR）引擎推荐 RapidOCR**：基于 ONNX Runtime 离线运行，不需要 GPU；工程代码为 Apache-2.0，模型来自 PaddleOCR（版权归百度，需核实模型许可）；轻量模型约 20 MB 以内（二手资料，需实测）。作为可选依赖安装，不装时退回手动标定。

公开研究已有类似流程。2025 年一篇论文用目标检测加 OCR 识别 SEM 比例尺；另一篇（YOLO-OCR）公开了约 2 万张带标注的比例尺图像，可作为验证数据。开源的 MicroScaleEditor 也用 RapidOCR 做离线识别，但其许可证页面上没有写明，不能直接用其代码。

**自动裁剪信息栏**：

1. 有元数据时直接用：例如 FEI 的成像分辨率与图片实际高度之差，就是信息栏高度。
2. 没有元数据时从底部向上找“统计特征与成像区明显不同”的水平带：大面积纯黑或纯白、文字笔画多、上沿有一条清晰的水平边界。
3. 裁剪只影响分析区域，原图和信息栏原样保留在结果里。

**验收**：

- 至少三家厂商的真实图片：元数据标定零误差；信息栏识别的像素尺寸与元数据相差 < 1%；自动裁剪全部正确。
- 识别失败时必须报“无法识别”，**绝不能给出错误标定而不提示**。

### 2.2 手动二维测量

工具：直线长度、折线长度、面积（多边形、自由画、魔棒）、周长、角度（三点或两线）、点计数（可分类别）、圆或椭圆拟合（直径）、线剖面（灰度沿线分布，用于测边缘宽度）。

**测量数据单独保存**：坐标保存为单独的测量记录（与微流控模块的修正记录同一机制），可撤销、可编辑、可复现，并汇总成表格。

**输出**：测量表（CSV、Excel）；带测量标注和比例尺的导出图（PNG、SVG）。

**需要注意的精度问题**：

- 标定不确定度会传到每个测量值，报告中写明标定来源。
- 样品倾斜时，倾转方向上的长度被投影缩短，按 1/cos(倾角) 校正（倾角取自元数据或手动输入）。
- 颗粒粒度的统计与报告方式参照 ISO 13322-1（静态图像分析）和 ISO 9276（粒度数据表示）。

**验收**：在已知几何形状的合成图上，长度、面积、角度误差不超过 1 个像素所对应的量；测量记录导出后重新载入完全一致。

### 2.3 图像处理

“荷电”（charging）表现不止一种，应分开处理：

| 现象 | 成因 | 推荐方法 | 能否真正“去除” |
| :--- | :--- | :--- | :--- |
| 沿扫描方向的明暗条纹 | 扫描过程中电荷积累与释放 | 逐行或逐列的中位数校平；条纹集中在固定方向时，用傅里叶或小波去条纹（文献中的主流后处理方法） | 能明显减轻 |
| 大范围亮度不均（一侧亮、中央亮） | 荷电、探测器几何、照明不均 | 大尺度背景估计后扣除或相除（高斯、滚球、多项式曲面） | 能 |
| 局部过亮、饱和区 | 严重荷电 | **标记为不可用区域**，不参与分割与测量，在报告中说明 | **不能**：饱和区信息已丢失，“修复”只是伪造 |
| 扫描线错位 | 荷电或振动导致行偏移 | 相邻行互相关后对齐 | 能 |

文献也指出，荷电最有效的办法在采集端（降低电压、短驻留时间交错扫描、镀膜）。软件处理是补救。这一点要写进手册，避免用户期望过高。

其他常用处理：

- 去噪：非局部均值、中值、双边滤波；多帧平均与漂移对齐。BM3D 效果好，但常用实现限制商用，暂不采用。Noise2Void 类自监督去噪效果更好，作为后续插件。
- 对比度：自动色阶、伽马、局部直方图均衡（CLAHE）。
- 锐化：反锐化掩模（只用于展示）。
- FIB-SEM 截面的帘幕（curtaining）条纹：同样用傅里叶或小波去条纹。文献指出强条纹有三维成因，二维处理只能部分去除。
- 倾斜校正（透视、投影缩短）。

**验收**：在干净的合成或真实图上人工注入条纹、亮度梯度、噪声、行错位，处理后与原图的误差下降到给定水平；饱和区 100% 被标记。

### 2.4 分割与自动测量

| 对象 | 推荐经典方法 | 输出 | 参考与要点 |
| :--- | :--- | :--- | :--- |
| **颗粒** | 局部阈值或 Otsu → 距离变换分水岭分开相互接触的颗粒（平台已有）；圆形颗粒可用找圆（已有）；边缘截断的颗粒按 ISO 规则排除或单独统计 | 粒径（等效圆径、Feret 直径）、圆度、长宽比、粒度分布（数量与体积加权）、团聚比例 | 深度模型（Cellpose-SAM、micro-SAM）作为插件；Cellpose-SAM 的训练数据含非商用部分，需在模型卡中标明 |
| **纤维** | 脊线增强（Sato、Frangi）→ 二值化 → 骨架化 → 距离变换得到沿骨架的直径分布；结构张量得到取向分布；交点、孔隙率 | 直径分布、取向分布与取向度、孔隙率、交点密度 | NIST 的 DiameterJ 在参考样品上误差约 2%，但独立评估发现结果依赖分割质量和像素尺寸，每根纤维宽约 13–16 个像素时最好。我们要在报告中提示“纤维太细，像素不够”的情况 |
| **尖端**（针尖、发射体、AFM 针尖、纳米针） | 提取轮廓 → 在尖端附近拟合圆（自动优化拟合范围）或多项式求曲率半径 → 在距尖端指定距离（如 1 µm）处取两侧切线求锥角；多个视角取平均 | 尖端曲率半径、锥角、长度、长径比 | 专利与原子探针、计量学文献中的通行做法；拟合范围对结果影响大，要做自动优化并报告不确定度 |
| 薄膜、孔、晶粒 | 阈值或分水岭（已有）；晶粒用边界增强 | 孔隙率、孔径、晶粒尺寸 | 路线图 S5 已列出；本计划只顺带支持孔隙率 |

**验收**：

- 合成数据：已知粒径分布、已知纤维直径与取向、已知尖端半径的渲染图；粒径与直径误差 < 2%，尖端半径误差 < 5%。
- 真实数据：EM3M 数据集（5,091 张电镜图、约 300 万个实例标注，Hugging Face 上公开，许可证待核实）中的颗粒子集；加上你提供的真实图片和人工测量。

### 2.5 自动分类

分两层：

1. **整图分类**：判断这张图拍的是什么（颗粒、纤维、尖端、薄膜、图案、多孔、MEMS 器件……），据此自动选择配方，接入现有的探针与规划器。
   - 训练和评估数据：NFFA-Europe SEM 数据集。约 2.1 万张 JPEG（1024×728），10 类，其中正好有颗粒、纤维、尖端；只有整图类别标签，没有像素标注。图片已去掉原始元数据。论文为 CC BY 4.0，**数据本身的许可证需到 B2SHARE 核实**。
   - 方法：先用图像特征加梯度提升（轻量、可解释），不够再上小型卷积网络，导出 ONNX 作为插件。
   - 注意：纤维类只有约 150 张，样本不均衡。
2. **目标分类**：一张图里的每个分割目标属于哪类（单个颗粒、团聚体、纤维段、碎屑、尖端）。先用形状描述量写规则：长宽比、实度、骨架长度与分支、等效直径与厚度之比。再用画笔训练式的交互分类器补充，平台已有类似机制。

**验收**：整图分类在 NFFA 留出集上的准确率（按类报告，特别是颗粒、纤维、尖端三类）；目标分类在人工标注集上的混淆矩阵。

### 2.6 倾转多角度三维重建

**原理**：样品绕共心（eucentric）轴倾转后再拍，不同高度的特征在两张图间产生视差。已知倾转角时，高度可由视差直接算出（立体摄影测量）。

**建议范围：输出 2.5D 高度图，不做完整的 360° 三维模型。** 完整三维需要大角度多方位拍摄，SEM 样品台的倾转范围有限。同类商业软件（MountainsSEM）也以高度图为主。

**流程**：

1. 读取倾转角，来自元数据或手动输入。
2. 粗对齐：相位相关，平台已有。
3. 按倾转轴方向校正。
4. 稠密匹配：半全局块匹配或光流，得到逐像素视差。
5. 视差换算成高度。
6. 多于两张时，按两两组合求高度后加权融合，同时估计每个像素的不确定度。
7. 输出高度图、等高线、剖面线、表面粗糙度参数（如 ISO 25178 的 Sa、Sq）、三维网格导出（STL/OBJ，路线图已列）。

**精度的主要影响因素**（文献）：倾转是否共心、倾转角的准确度、放大倍数标定、图像清晰度、匹配算法的稳健性。一项对商业软件的仿真比较显示，有纹理的线条高度误差可接近 1 nm，**但在均匀、低对比区域，高度误差可达约 46%**。所以每个像素都要给出匹配置信度，低置信区域在高度图上标出。

**验收**：

- 用已知高度图渲染出倾转图对（考虑噪声和倾转角误差），重建高度误差 < 5%（有纹理区域）。
- 用实物标准样品（金字塔或台阶标准件）实测。

**开源参考**：COLMAP、Meshroom（AliceVision）可做完整多视角重建，但面向普通相机；SEM 场景只作参考，不集成。

## 三、平台改造：两个独立模块

检查结果：

- **通用部分**：引擎、配方、溯源、质控、批处理、插件、诊断包。
- **液滴专用、需要拆开的部分**：
  - 主窗口：约 1,200 行，几乎全是液滴流程；
  - HTML 报告：液滴专用章节；
  - 探针与规划器：只认识液滴；
  - 批量统计的指标表：液滴指标；
  - 在线监控；
  - 合成数据生成器。

改造方案：

1. **模块接口**。每个模块（`vexel.modules.droplet`、`vexel.modules.sem`）声明：
   - 名称；
   - 算子与内置配方；
   - 界面工作区（一个独立的窗口部件）；
   - 报告章节；
   - 批量统计的指标表；
   - 复核适配器；
   - 探针与规划规则；
   - 合成数据与验证。
2. **应用外壳**。启动时选择模块（或按打开的文件自动建议），各模块的工作区互不干扰。菜单、诊断包、模型设置、批量窗口共用。
3. **把液滴现有功能原样搬进模块接口**。用全部现有测试和基准保证行为不变，这是第一步。
4. **命令行**：按模块分组（如 `vexel sem calibrate`、`vexel sem measure`），保留现有命令不变。
5. **数据模型补充**：
   - 单张图像：已支持，即 T=1 的情况；
   - 标定记录：来源、可信度、是否经人确认；
   - 测量与标注层：与修正记录同一机制；
   - 掩膜（不可用区域）。

## 四、分阶段计划

估算按“一人加 AI 辅助”。每个阶段都有验收，验收通过才进入下一阶段。

| 阶段 | 内容 | 主要交付 | 验收 | 估计 |
| :--- | :--- | :--- | :--- | :--- |
| **M0 平台模块化** | 模块接口、应用外壳、把液滴搬入模块 | 两个模块的框架，液滴行为不变 | 全部现有测试和基准通过；液滴界面截图一致 | 1–1.5 周 |
| **M1 读取与标定** | 厂商元数据读取（FEI、Zeiss、TESCAN、Hitachi、JEOL）、信息栏检测与裁剪、比例尺与文字识别（可选依赖）、手动标定、标定记录 | `vexel sem calibrate`；界面的标定确认 | 见 2.1 | 2 周 |
| **M2 手动测量** | 测量画布与全部工具、测量表、导出带标注与比例尺的图 | SEM 工作区第一版 | 见 2.2；新用户 10 分钟内完成一组测量 | 2 周 |
| **M3 图像处理** | 去条纹、背景校平、饱和区标记、行错位校正、去噪、对比度、多帧平均 | 处理算子与前后对比视图 | 见 2.3 | 1.5 周 |
| **M4 分割与自动测量** | 颗粒、纤维、尖端三套配方与报告；批量与分组统计接入 | 三个内置配方 | 见 2.4 | 3 周 |
| **M5 自动分类** | 整图分类（插件）、目标分类、接入规划器 | “自动规划”支持 SEM | 见 2.5 | 2 周 |
| **M6 倾转三维** | 倾转图对与多角度融合、高度图与不确定度、粗糙度、网格导出 | `vexel sem tilt3d`；三维视图 | 见 2.6 | 3 周 |
| **M7 SEM 内测** | 文档、示例数据、内测说明，复用微流控的内测流程 | SEM 内测版 | 测试者真实图片上的验收 | 1 周 |

合计约 15–16 周。**建议先做 M0 → M1 → M2**（约 5 周）：做完就是一个“自动标定、手动测量”都可用的 SEM 工具，可以先给测试者用，再按反馈决定 M3–M6 的先后。

**与微流控内测的关系**：微流控内测主要靠测试者和你推进，我这边的工作量不大（数据接收、修 bug、安装包）。M0 会改动主窗口，建议在发出微流控内测安装文件之后再开始，避免测试版本中途变化。

## 五、风险

| 风险 | 应对 |
| :--- | :--- |
| 没有 SEM 的设计伙伴和真实图片 | 路线图规定进入新场景前先有设计伙伴（原排在 S5）。至少需要几位真实用户和三家以上厂商的样图，才能验收标定和分割 |
| 文字识别不可靠导致标定错误 | 元数据优先；识别结果必须人确认；两种独立估计交叉核对；识别失败明确报错 |
| 荷电“去除”被误解为恢复信息 | 饱和区只标记不修复；手册写清采集端措施 |
| 深度模型与数据集的许可证 | 走插件接口和模型卡；NFFA、EM3M、YOLO-OCR 数据集、RapidOCR 模型的许可证在使用前逐一核实 |
| 倾转三维精度被高估 | 只承诺 2.5D 高度图；逐像素给置信度；用合成和标准样品验收 |

第一位用户是半导体制造商，这改变了 M4 的重点和几项工程要求：

**A. 测量重点转向半导体计量。** 半导体 SEM 主要做尺寸计量。M2 和 M4 相应增加或调整：

| 功能 | 内容 | 依据与要点 |
| :--- | :--- | :--- |
| **线宽（CD）与周期** | 在线条与间隔图案上沿垂直方向取多条灰度剖面，按可选的边缘定义（阈值百分比、最大梯度、Canny）找左右边缘，报告线宽、间隔、周期及其分布 | 不同边缘定义给出的线宽不同，因此必须在结果中写明所用定义 |
| **线边缘粗糙度（LER）与线宽粗糙度（LWR）** | 沿线提取边缘位置序列 → 3σ、功率谱（PSD）、相关长度；**扣除图像噪声带来的虚高** | 文献指出目前**没有官方统一的粗糙度测量算法**；测得的粗糙度混有噪声造成的表观波动，要做噪声偏差校正，并报告采样参数 |
| **截面计量** | 截面图倾斜校正 → 识别各层界面 → 逐列测层厚、界面粗糙度、沟槽深度与宽度、侧壁角 | 目前常用专有软件手工标注，是可以自动化的空白；FIB 截面可能有畸变，需要校正或提示 |
| **接触孔与通孔** | 找圆、椭圆拟合，得到孔径、圆度、缺失孔计数 | 复用颗粒与找圆算子 |
| **缺陷颗粒** | 颗粒分割加尺寸与位置统计 | 原 M4 颗粒部分 |
| 尖端 | 保留（探针、针尖） | 原 M4 |
| 纤维 | **降低优先级**，排到 M4 最后或之后 | 半导体场景较少用到 |

**B. 计量重复性作为验收标准。** 半导体用户看重测量的重复性：同一位置重复拍摄、重复测量，结果的分散程度（3σ）要小。每个计量功能除了准确度，还要在重复图像上报告重复性。

**C. 数据保密与离线使用。** 半导体工厂通常不允许数据外传，计算机常与外网隔离：

- **企业离线模式**：管理员可以用配置文件锁定“禁止一切网络请求”，大模型规划不可开启。现有的 `VEXEL_OFFLINE` 环境变量可以扩展成不可被用户关闭的设置。
- **离线安装包**：把 wheel 和全部依赖一起打包，不需要访问 PyPI。这使第七阶段的安装包优先级提高。可以先做一个“离线依赖包”（wheel 加全部依赖的 wheel），再做正式安装程序。
- 诊断包已不含图像，可以直接给用户用；还要增加“只含版本信息”的最小模式。
- 以单位身份签名（已确认）对企业 IT 审核很重要。

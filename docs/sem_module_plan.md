## 一、目标与原则

**目标**：在 Vexel 平台上新增一个 SEM 模块，与微流控模块并列、独立运行。覆盖：

- 手动二维测量：长度、面积、角度、周长、计数；
- 自动标定与信息栏裁剪；
- SEM 常见图像处理（荷电伪影、亮度对比度等）；
- 常见分割：颗粒、纤维、尖端；
- 图像与目标的自动分类；
- 倾转多角度成像的三维重建。

**原则**（沿用平台已有做法）：

1. **两个模块共用一个平台。** 共用的有数据底座、算子注册表、配方引擎、溯源、质控、批处理与分组统计、报告框架、插件接口、智能体、诊断包。模块各自提供算子、配方、界面工作区、报告内容和验证数据。一个模块出问题不影响另一个。
2. **标定必须可追溯。** 每张图的像素尺寸都记录来源（仪器元数据、信息栏识别、手动）和可信度。识别出来的标定要人确认后才算数。
3. **处理不改变测量的依据。** 图像处理只用于显示和分割，测量始终在已标定的原始几何上进行。每一步处理都写入溯源记录；只为美观的处理（如锐化）单独标明。
4. **能用经典方法就不用深度模型。** 深度模型只作为插件接入，记录许可证和训练数据（第六阶段的插件接口已经就绪）。
5. **每项自动功能都要有可量化的验收**：合成数据给出精确真值，真实数据给出人工参照。

## 二、调研结论与推荐做法

### 2.1 读取与自动标定

**最可靠的标定来自仪器写在文件里的元数据，其次才是识别图片下方的信息栏。** 推荐三级来源，依次尝试：

| 级别 | 来源 | 做法 | 可信度 |
| :--- | :--- | :--- | :--- |
| 1 | 仪器元数据 | Thermo Fisher（FEI）：TIFF 私有标签 34680/34682 中的 INI 文本，`PixelWidth` 单位为米；Zeiss：标签 34118（SmartSEM 参数块，“Image Pixel Size”）；TESCAN：同名 `.hdr` 文本，`PixelSizeX/Y` 单位为米；Hitachi：同名 `.txt` 中的 `PixelSize`；JEOL：同名 `.txt`，字段名待用真实文件核对。`tifffile` 已能解析 FEI 与 Zeiss 的标签 | 高，自动采用 |
| 2 | 信息栏识别 | ① 找到信息栏（见下）；② 在信息栏和图像下部找比例尺线段，测其像素长度；③ 识别比例尺旁的数字和单位，以及放大倍数、视场宽度（HFW）、工作距离；④ 交叉核对：比例尺换算出的像素尺寸与视场宽度 ÷ 图像宽度应一致 | 中，**需人确认**；两种估计一致时可信度提高 |
| 3 | 手动 | 在比例尺两端各点一下并输入长度；或直接输入像素尺寸 | 由人负责 |

**文字识别（OCR）引擎推荐 RapidOCR**：基于 ONNX Runtime 离线运行，不需要 GPU；工程代码为 Apache-2.0，模型来自 PaddleOCR（版权归百度，需核实模型许可）；轻量模型约 20 MB 以内（二手资料，需实测）。作为可选依赖安装，不装时退回手动标定。

公开研究已有类似流程。2025 年一篇论文用目标检测加 OCR 识别 SEM 比例尺；另一篇（YOLO-OCR）公开了约 2 万张带标注的比例尺图像，可作为验证数据。开源的 MicroScaleEditor 也用 RapidOCR 做离线识别，但其许可证页面上没有写明，不能直接用其代码。

**自动裁剪信息栏**：

1. 有元数据时直接用：例如 FEI 的成像分辨率与图片实际高度之差，就是信息栏高度。
2. 没有元数据时从底部向上找“统计特征与成像区明显不同”的水平带：大面积纯黑或纯白、文字笔画多、上沿有一条清晰的水平边界。
3. 裁剪只影响分析区域，原图和信息栏原样保留在结果里。

**验收**：

- 至少三家厂商的真实图片：元数据标定零误差；信息栏识别的像素尺寸与元数据相差 < 1%；自动裁剪全部正确。
- 识别失败时必须报“无法识别”，**绝不能给出错误标定而不提示**。

### 2.2 手动二维测量

工具：直线长度、折线长度、面积（多边形、自由画、魔棒）、周长、角度（三点或两线）、点计数（可分类别）、圆或椭圆拟合（直径）、线剖面（灰度沿线分布，用于测边缘宽度）。

**测量数据单独保存**：坐标保存为单独的测量记录（与微流控模块的修正记录同一机制），可撤销、可编辑、可复现，并汇总成表格。

**输出**：测量表（CSV、Excel）；带测量标注和比例尺的导出图（PNG、SVG）。

**需要注意的精度问题**：

- 标定不确定度会传到每个测量值，报告中写明标定来源。
- 样品倾斜时，倾转方向上的长度被投影缩短，按 1/cos(倾角) 校正（倾角取自元数据或手动输入）。
- 颗粒粒度的统计与报告方式参照 ISO 13322-1（静态图像分析）和 ISO 9276（粒度数据表示）。

**验收**：在已知几何形状的合成图上，长度、面积、角度误差不超过 1 个像素所对应的量；测量记录导出后重新载入完全一致。

### 2.3 图像处理

“荷电”（charging）表现不止一种，应分开处理：

| 现象 | 成因 | 推荐方法 | 能否真正“去除” |
| :--- | :--- | :--- | :--- |
| 沿扫描方向的明暗条纹 | 扫描过程中电荷积累与释放 | 逐行或逐列的中位数校平；条纹集中在固定方向时，用傅里叶或小波去条纹（文献中的主流后处理方法） | 能明显减轻 |
| 大范围亮度不均（一侧亮、中央亮） | 荷电、探测器几何、照明不均 | 大尺度背景估计后扣除或相除（高斯、滚球、多项式曲面） | 能 |
| 局部过亮、饱和区 | 严重荷电 | **标记为不可用区域**，不参与分割与测量，在报告中说明 | **不能**：饱和区信息已丢失，“修复”只是伪造 |
| 扫描线错位 | 荷电或振动导致行偏移 | 相邻行互相关后对齐 | 能 |

文献也指出，荷电最有效的办法在采集端（降低电压、短驻留时间交错扫描、镀膜）。软件处理是补救。这一点要写进手册，避免用户期望过高。

其他常用处理：

- 去噪：非局部均值、中值、双边滤波；多帧平均与漂移对齐。BM3D 效果好，但常用实现限制商用，暂不采用。Noise2Void 类自监督去噪效果更好，作为后续插件。
- 对比度：自动色阶、伽马、局部直方图均衡（CLAHE）。
- 锐化：反锐化掩模（只用于展示）。
- FIB-SEM 截面的帘幕（curtaining）条纹：同样用傅里叶或小波去条纹。文献指出强条纹有三维成因，二维处理只能部分去除。
- 倾斜校正（透视、投影缩短）。

**验收**：在干净的合成或真实图上人工注入条纹、亮度梯度、噪声、行错位，处理后与原图的误差下降到给定水平；饱和区 100% 被标记。

### 2.4 分割与自动测量

| 对象 | 推荐经典方法 | 输出 | 参考与要点 |
| :--- | :--- | :--- | :--- |
| **颗粒** | 局部阈值或 Otsu → 距离变换分水岭分开相互接触的颗粒（平台已有）；圆形颗粒可用找圆（已有）；边缘截断的颗粒按 ISO 规则排除或单独统计 | 粒径（等效圆径、Feret 直径）、圆度、长宽比、粒度分布（数量与体积加权）、团聚比例 | 深度模型（Cellpose-SAM、micro-SAM）作为插件；Cellpose-SAM 的训练数据含非商用部分，需在模型卡中标明 |
| **纤维** | 脊线增强（Sato、Frangi）→ 二值化 → 骨架化 → 距离变换得到沿骨架的直径分布；结构张量得到取向分布；交点、孔隙率 | 直径分布、取向分布与取向度、孔隙率、交点密度 | NIST 的 DiameterJ 在参考样品上误差约 2%，但独立评估发现结果依赖分割质量和像素尺寸，每根纤维宽约 13–16 个像素时最好。我们要在报告中提示“纤维太细，像素不够”的情况 |
| **尖端**（针尖、发射体、AFM 针尖、纳米针） | 提取轮廓 → 在尖端附近拟合圆（自动优化拟合范围）或多项式求曲率半径 → 在距尖端指定距离（如 1 µm）处取两侧切线求锥角；多个视角取平均 | 尖端曲率半径、锥角、长度、长径比 | 专利与原子探针、计量学文献中的通行做法；拟合范围对结果影响大，要做自动优化并报告不确定度 |
| 薄膜、孔、晶粒 | 阈值或分水岭（已有）；晶粒用边界增强 | 孔隙率、孔径、晶粒尺寸 | 路线图 S5 已列出；本计划只顺带支持孔隙率 |

**验收**：

- 合成数据：已知粒径分布、已知纤维直径与取向、已知尖端半径的渲染图；粒径与直径误差 < 2%，尖端半径误差 < 5%。
- 真实数据：EM3M 数据集（5,091 张电镜图、约 300 万个实例标注，Hugging Face 上公开，许可证待核实）中的颗粒子集；加上你提供的真实图片和人工测量。

### 2.5 自动分类

分两层：

1. **整图分类**：判断这张图拍的是什么（颗粒、纤维、尖端、薄膜、图案、多孔、MEMS 器件……），据此自动选择配方，接入现有的探针与规划器。
   - 训练和评估数据：NFFA-Europe SEM 数据集。约 2.1 万张 JPEG（1024×728），10 类，其中正好有颗粒、纤维、尖端；只有整图类别标签，没有像素标注。图片已去掉原始元数据。论文为 CC BY 4.0，**数据本身的许可证需到 B2SHARE 核实**。
   - 方法：先用图像特征加梯度提升（轻量、可解释），不够再上小型卷积网络，导出 ONNX 作为插件。
   - 注意：纤维类只有约 150 张，样本不均衡。
2. **目标分类**：一张图里的每个分割目标属于哪类（单个颗粒、团聚体、纤维段、碎屑、尖端）。先用形状描述量写规则：长宽比、实度、骨架长度与分支、等效直径与厚度之比。再用画笔训练式的交互分类器补充，平台已有类似机制。

**验收**：整图分类在 NFFA 留出集上的准确率（按类报告，特别是颗粒、纤维、尖端三类）；目标分类在人工标注集上的混淆矩阵。

### 2.6 倾转多角度三维重建

**原理**：样品绕共心（eucentric）轴倾转后再拍，不同高度的特征在两张图间产生视差。已知倾转角时，高度可由视差直接算出（立体摄影测量）。

**建议范围：输出 2.5D 高度图，不做完整的 360° 三维模型。** 完整三维需要大角度多方位拍摄，SEM 样品台的倾转范围有限。同类商业软件（MountainsSEM）也以高度图为主。

**流程**：

1. 读取倾转角，来自元数据或手动输入。
2. 粗对齐：相位相关，平台已有。
3. 按倾转轴方向校正。
4. 稠密匹配：半全局块匹配或光流，得到逐像素视差。
5. 视差换算成高度。
6. 多于两张时，按两两组合求高度后加权融合，同时估计每个像素的不确定度。
7. 输出高度图、等高线、剖面线、表面粗糙度参数（如 ISO 25178 的 Sa、Sq）、三维网格导出（STL/OBJ，路线图已列）。

**精度的主要影响因素**（文献）：倾转是否共心、倾转角的准确度、放大倍数标定、图像清晰度、匹配算法的稳健性。一项对商业软件的仿真比较显示，有纹理的线条高度误差可接近 1 nm，**但在均匀、低对比区域，高度误差可达约 46%**。所以每个像素都要给出匹配置信度，低置信区域在高度图上标出。

**验收**：

- 用已知高度图渲染出倾转图对（考虑噪声和倾转角误差），重建高度误差 < 5%（有纹理区域）。
- 用实物标准样品（金字塔或台阶标准件）实测。

**开源参考**：COLMAP、Meshroom（AliceVision）可做完整多视角重建，但面向普通相机；SEM 场景只作参考，不集成。

## 三、平台改造：两个独立模块

检查结果：

- **通用部分**：引擎、配方、溯源、质控、批处理、插件、诊断包。
- **液滴专用、需要拆开的部分**：
  - 主窗口：约 1,200 行，几乎全是液滴流程；
  - HTML 报告：液滴专用章节；
  - 探针与规划器：只认识液滴；
  - 批量统计的指标表：液滴指标；
  - 在线监控；
  - 合成数据生成器。

改造方案：

1. **模块接口**。每个模块（`vexel.modules.droplet`、`vexel.modules.sem`）声明：
   - 名称；
   - 算子与内置配方；
   - 界面工作区（一个独立的窗口部件）；
   - 报告章节；
   - 批量统计的指标表；
   - 复核适配器；
   - 探针与规划规则；
   - 合成数据与验证。
2. **应用外壳**。启动时选择模块（或按打开的文件自动建议），各模块的工作区互不干扰。菜单、诊断包、模型设置、批量窗口共用。
3. **把液滴现有功能原样搬进模块接口**。用全部现有测试和基准保证行为不变，这是第一步。
4. **命令行**：按模块分组（如 `vexel sem calibrate`、`vexel sem measure`），保留现有命令不变。
5. **数据模型补充**：
   - 单张图像：已支持，即 T=1 的情况；
   - 标定记录：来源、可信度、是否经人确认；
   - 测量与标注层：与修正记录同一机制；
   - 掩膜（不可用区域）。

## 四、分阶段计划

估算按“一人加 AI 辅助”。每个阶段都有验收，验收通过才进入下一阶段。

| 阶段 | 内容 | 主要交付 | 验收 | 估计 |
| :--- | :--- | :--- | :--- | :--- |
| **M0 平台模块化** | 模块接口、应用外壳、把液滴搬入模块 | 两个模块的框架，液滴行为不变 | 全部现有测试和基准通过；液滴界面截图一致 | 1–1.5 周 |
| **M1 读取与标定** | 厂商元数据读取（FEI、Zeiss、TESCAN、Hitachi、JEOL）、信息栏检测与裁剪、比例尺与文字识别（可选依赖）、手动标定、标定记录 | `vexel sem calibrate`；界面的标定确认 | 见 2.1 | 2 周 |
| **M2 手动测量** | 测量画布与全部工具、测量表、导出带标注与比例尺的图 | SEM 工作区第一版 | 见 2.2；新用户 10 分钟内完成一组测量 | 2 周 |
| **M3 图像处理** | 去条纹、背景校平、饱和区标记、行错位校正、去噪、对比度、多帧平均 | 处理算子与前后对比视图 | 见 2.3 | 1.5 周 |
| **M4 分割与自动测量** | 颗粒、纤维、尖端三套配方与报告；批量与分组统计接入 | 三个内置配方 | 见 2.4 | 3 周 |
| **M5 自动分类** | 整图分类（插件）、目标分类、接入规划器 | “自动规划”支持 SEM | 见 2.5 | 2 周 |
| **M6 倾转三维** | 倾转图对与多角度融合、高度图与不确定度、粗糙度、网格导出 | `vexel sem tilt3d`；三维视图 | 见 2.6 | 3 周 |
| **M7 SEM 内测** | 文档、示例数据、内测说明，复用微流控的内测流程 | SEM 内测版 | 测试者真实图片上的验收 | 1 周 |

合计约 15–16 周。**建议先做 M0 → M1 → M2**（约 5 周）：做完就是一个“自动标定、手动测量”都可用的 SEM 工具，可以先给测试者用，再按反馈决定 M3–M6 的先后。

**与微流控内测的关系**：微流控内测主要靠测试者和你推进，我这边的工作量不大（数据接收、修 bug、安装包）。M0 会改动主窗口，建议在发出微流控内测安装文件之后再开始，避免测试版本中途变化。

## 五、风险

| 风险 | 应对 |

**做法上的决定**：

- 边缘先在区域的平均剖面上按斜率找出（适用于多层灰度），再逐行按所选定义精确定位；斜向的线条先估计倾斜（搜索范围限制在半个周期内，避免锁到相邻线条），线宽按垂直于线的方向计。
- 噪声扣除：对边缘位置功率谱拟合“粗糙度模型 + 白噪声底”，拟合失败时取最高频段的平均功率。扣除的前提是噪声只“加上”抖动、不改变真实的边缘起伏：最初逐行在搜索窗口内取高低平台，边缘偏向一侧时那一侧的平台不足、混入边缘像素，使起伏被压缩（噪声 σ 0.25 时斜率 0.80），扣除后反而偏低 15%。改为平台取自平均剖面相邻间隙的中段、只按每行整体亮度平移后，边缘起伏不再被压缩（斜率 ≥ 0.99），扣除后与真实边缘差 ≤ 2%。

- 颗粒阈值取颗粒核心与远处背景灰度的中点（两类均值会被模糊的边缘像素拉近，使颗粒偏大）；默认平滑 0.5 像素（平滑使小颗粒轮廓内收）。
- 每个自动测量只存“方法、区域、设置”，和手动测量一样每次重算，所以标定、倾斜校正、图像处理改变后结果随之更新。

**做法**：按你的决定，先完成开发，最后用真实图片统一验收。M5 拆成两半：前半是不需要训练数据的规则识别与规划，接入平台已有的智能体（探针 → 规划 → 试运行 → 人确认 → 配方记忆）；后半是用你整理的图片训练的分类器，等数据到位再做。

**交付**：

- `vexel/packs/sem/recognize.py`（SEM 探针）：识别线条与间隔、接触孔阵列、颗粒、截面层叠、截面轮廓、尖端、其他；依据是边缘方向一致性、频谱的一维周期、剖面的规则重复（自相关）、目标的形状与边界清晰度（两类灰度之间的像素比例）、目标间距的规则性（最近邻距离）、目标与图像边缘的关系。没有足够把握时给出“无法确定”及候选，不猜。同时测量噪声、扫描行条纹、亮度不均、饱和，并建议处理步骤；会损伤测量的步骤不建议（水平结构不逐行校平，测粗糙度前不去噪）。
- `vexel/packs/sem/plan.py`（SEM 规划器）：从目标文字（中英文）和识别结果选方法、设置（亮暗、边缘定义、尺寸）、区域（单个目标取外框加背景）、处理步骤，每项写明理由；试运行并按方法检查（线条数、各线线宽差、孔的圆度与相连、界面数、曲率半径随拟合范围的变化等），不通过时依次尝试其他设置（灰度反过来、换边缘定义、平均、局部阈值、去噪），保留最好的一次。状态：可用 / 请核对 / 需要你来决定。
- 平台智能体的改动：模型层按任务区分（液滴、SEM），SEM 的可调设置清单直接取自各测量方法的参数定义；语言模型（如已配置并被组织策略允许）可以选择方法和调整设置，全部经清单与范围检查，并经试运行；测粗糙度时去噪的建议一律不采用。配方记忆支持各模块自己的指纹与距离，SEM 的记录单独存放（`memory/sem.jsonl`），按图像类型匹配，只借用被人采用过的设置。
- 入口：SEM 窗口“自动测量”页的“自动规划”（后台运行，显示理由，确认后加入记录，可撤销）；`vexel sem plan`（`--apply`）；`vexel sem analyze --auto`（成批图像先规划再测量）；MCP 工具 `sem_calibrate`、`sem_plan`、`sem_analyze`（助手只能在用户同意后 `apply`）。

**验收**（`tests/benchmarks/sem_recognition_eval.py`，每类 20 张随机合成图：方向、亮暗、亮边、倾斜、大小、噪声都随机；四组随机种子）：

| 项目 | 结果 | 要求 |
| :--- | :--- | :--- |
| 识别正确率 | 97.1%–99.3% | ≥ 95% |
| 有把握地识别错（给出错误的测量类型） | 0 | 0 |
| 自动规划的结果在容差内（规划通过试运行，测量值与几何真值或正确设置下的结果一致） | 96.6%–100% | ≥ 95% |
| 真实图片（Zeiss 公开样图，多晶组织） | 3 张都识别为“其他”，不归入任何测量类型 | 不误判 |

**过程中发现并修正的问题**：

- 识别：频谱峰的方向判断在低频处按角度会误差很大，改为按频率格距离判断；孔阵列改用目标间距的规则性而非频谱判断（方形阵列的频谱峰在很多方向上）；纹理与颗粒以“两类灰度之间的像素比例”区分；只有几个周期的水平等距条带（周期性多层膜或水平线条）判为“无法确定”。
- 截面层厚：弱界面（相邻层灰度差小）紧挨强界面时被漏掉；层界面改为按平均剖面自身的噪声判断（不低于最强界面的 5%）。
- 尖端曲率半径：原先选“半径最稳定”的拟合范围，在小范围上会偏小（短弧拟合不可靠）；改为取拟合残差突增（开始包含锥面）之前的最大范围，没有明显突增时退回原规则。80 个随机尖端：中位误差 0.7%，90% 在 3.5% 以内；半径小于 10 像素时可能超过 5%，结果会提示。
- 颗粒：规划不再按典型直径的 30% 设最小直径（会丢掉粒度分布中的小颗粒）。
- 接触孔（无亮环）的孔径在随机样本上偏小 0.15–0.40 像素（平均 0.26），小孔更明显：模糊使弯曲边缘的半高位置内收。

**限度与未完成**：

- 识别规则基于合成数据设计和验证，真实图像（特别是 CD-SEM 图、截面图中线条立在衬底上、带亮边的颗粒）可能需要调整阈值：这是最终验收的重点之一。
- “线条”的约定：较窄的条纹按线条计（接近 1:1 时取亮条）；与对方的约定不同时，在设置中改“线条是”。
- M5 后半（用你的分类目录训练的整图分类器，冻结特征 + 小分类器，离线运行）待你的图片。

## 十三、M6 完成情况：倾转 2.5D 高度图（2026-11-20）

**交付**：`vexel/packs/sem/tilt3d.py`（两张或多张倾转图 → 高度图，逐像素置信度与不确定度；校平、ISO 25178 粗糙度、高度剖面、ISO 5436-1 两平行平面台阶高度；高度图 TIFF、STL/OBJ 网格、彩色高度图、三维预览）；SEM 窗口“三维”页（添加倾转图并填写倾角、倾转轴方向、校平、重建在后台运行、显示原图/高度图/置信度、画高度剖面、框选测台阶、三维预览、导出、Excel 中的“三维”页）；重建的“配方”（其他图及其 SHA-256、倾角、设置、剖面与台阶）保存在参考图的测量记录中；`vexel sem tilt3d`；合成数据 `height_map`、`surface_texture`、`tilt_view`；`tests/test_sem_tilt3d.py`；验收脚本 `tests/benchmarks/sem_tilt3d_eval.py`。

**做法**：第二张图先按 cos φa / cos φb 沿垂直于倾转轴的方向缩放（平面即可完全对上），整体对齐（相位相关），再逐像素匹配（TV-L1 光流，亚像素）；剩下的视差与高度成正比：z = (ya·cos φb − yb·cos φa) / sin(φa − φb)。多于两张时每张与参考图配对，按置信度与精度加权平均，两两不一致处不确定度增大。置信度 = 局部匹配相关 × 垂直于轴方向的纹理强度（图像边缘 3% 降权）；不确定度 = 图像噪声 / 纹理梯度 × cos φ / sin Δφ，加匹配本身的下限（在合成数据上标定）。

**验收（2.6，合成数据）**：

| 项目 | 结果 | 要求 |
| :--- | :--- | :--- |
| 高度图误差（±5°，噪声 0.02；棱台、台阶、球冠、正弦、随机粗糙面） | 高度范围的 2.8%–4.4% | < 5%（有纹理区域） |
| 噪声加大到 0.05 | 4.4%–8.6%；±10° 时 3.6%，五张（−10°…10°）时 2.7% | 记录 |
| 倾转轴竖直 | 2.8% | < 5% |
| 台阶高度（两平行平面拟合；水平样品与整体倾斜的样品，各 4 种纹理） | 最大误差 4.9%（水平）、3.0%（倾斜）；误差都在报告不确定度的 2 倍以内 | < 5% |
| 无纹理的平坦区 | 83% 标为不可靠；有纹理处 100% 可靠 | 标出 |
| 报告的不确定度与实际误差之比 | 中位数 0.97；81.5% 的情形在 2 倍以内 | 量级正确 |

**过程中发现并修正的问题**：

- 匹配噪声直接放大为高度噪声（10° 倾角差时约 5.7 倍）：TV-L1 改用更强的正则化并对高度做 1.5 像素加权平滑，误差约减半。
- 最初的不确定度（光流残差）与实际误差相差 0.8–6.7 倍，改用“噪声 / 纹理”模型并加下限后中位数比值 0.97。
- 台阶高度：平面校平会把台阶当作倾斜去掉（得到错误的台阶高度），改为 ISO 5436-1 的两平行平面拟合；图像边缘的匹配较弱，会在边缘附近产生假斜率，边缘 3% 降权；台阶的不确定度原先只含拟合统计误差（偏小约 20 倍），改为同时计入高度图本身的不确定度。

**限度**：

- 高度噪声约为 1–1.5 像素（10° 倾角差、图像噪声 0.02），与起伏大小无关；起伏小于约 25 像素时相对误差会超过 5%。加大倾角差（10°–15°）或增加图像张数可以降低噪声。
- 慢变的整体误差（跨图像约 1 像素）会影响相距很远的两个区域之间的台阶高度。
- 模型按平行投影、共心倾转处理；放大倍数很低（透视明显）或倾转不共心时会出现整体倾斜，校平可去掉一部分。
- 实物验收需要台阶或金字塔标准样品的倾转图组。

## 十四、真实图片验收（第一轮，2026-11-27）

**数据**：远端整理的 `Dataset/SEM`（不进仓库）：52 张 Phenom（Pharos、ProX、XL、Pure）样图，JPEG，带信息栏；3 个 ImageJ 保存的 FIB-SEM 序列；2 张拼接大图（6.7 亿、10.6 亿像素）。都不是半导体 CD-SEM 图片，半导体计量的验收仍等 Hitachi 原图。真值：每张信息栏的比例尺与视场宽度（FW）由人读出，每张图适合的测量类型由人判断（`tests/benchmarks/real/sem_gallery_truth.csv`）。

| 项目 | 修正前 | 修正后 | 要求 |
| :--- | :--- | :--- | :--- |
| 打开、标定、规划不崩溃 | 52/52 | 52/52 | 全部 |
| 像素尺寸与 FW ÷ 宽度相差 ≤ 1% | 36/52 | 51/52 | （记录） |
| 相差 > 1% 而没有提示 | 16 | 0 | 0 |
| 做了视场宽度核对 | 0/52 | 52/52 | 全部 |
| ImageJ 序列的标定 | 未标定 | 3/3 准确 | 准确 |
| 拼接大图 | 读入约 1–8.5 GB 内存 | 读像素之前拒绝并说明 | 不耗尽内存 |
| 识别：认错 | 2 | 0 | 0 |
| 识别：认出（21 张有明确测量对象） | 2 | 4 | （记录） |
| 每张用时 | 0.5–1.6 s | 0.5–1.6 s | < 3 s |

**发现并修正的问题**：

- 比例尺两端：JPEG 压缩让比例尺上下沿整条带一圈亮边，端点刻度的位置被算到了里面约 12 像素，像素尺寸偏大约 6%（14 张）。现在只有比亮边伸得更远的列才算刻度。
- Phenom 把视场宽度写作“FW”，原来只认 HFW / Width，52 张都没有核对。
- 信息栏表格中的数值（FW、WD）被当成比例尺的标注（3 张，像素尺寸错 2–2400 倍）。现在表头下方的数值不再当作标注。
- 视场宽度与比例尺都有时，原来只用比例尺、相差 2% 以内不提示；现在用更精确的一个，按两者的读数误差决定是否提示。
- ImageJ 写入的标定（分辨率标签 + 单位）没有读取。
- 单张图片没有大小上限：10 亿像素的拼接图会耗尽内存。

**识别**：试过把“灰度在两类之间”的判据按边界长度归一，召回提高但把组织、断口等纹理认成颗粒（20 张认错），已撤回。规则方法在多样的真实图片上宁可不认，这符合“不猜”的原则；提高认出率需要训练的分类器（M5 后半），这 52 张带标注的图是它的第一批评估数据。
